# CNTA E-file — live demo

**Open the app:** https://ericluc251-pixel.github.io/cnta-efile-app/

A working demo of the e-file app for Chloe Nguyen Tax Advisory:

- **Client portal** in English, Tiếng Việt and Español: questionnaire, status tracker, plain-language return summary, Form 8879 e-signature, fee payment, messages.
- **Staff workspace**: returns list, preparer interview, automatic tax calculation and checks, reviewer approval, transmission, IRS acknowledgements, Form 4868 extensions, and routing of unsupported returns to Drake.

Everything runs in your browser. Clients are **fictional**, the IRS is a **simulator** (nothing is sent to the IRS), and your changes stay in your browser (use *Reset demo data* on the sign-in page to start over).

This repository holds only the built page. The source code is private.
